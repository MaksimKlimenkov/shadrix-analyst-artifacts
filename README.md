## Облачная система контроля доступа

Выпускная квалификационная работа о системе, которая позволяет централизованно управлять доступом сотрудников, использовать смартфон как пропуск и подключать физические контроллеры дверей.

Здесь собраны аналитические артефакты проекта: требования, схема системы, модель данных, алгоритм принятия решения и презентация результата.
